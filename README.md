# GNITS Smart Admission Portal

## Project Description

GNITS Smart Admission Portal is a web-based admission management system developed to simplify and automate the admission process for students applying under different admission categories such as JEE, NRI, and OCI. The portal enables students to submit applications online, upload required documents, make payments securely, and receive confirmation emails.

The system also provides an admin dashboard for managing applications, verifying student details, and monitoring admission records efficiently.

---

## Features

### Student Features
- Online Admission Application
- Personal & Academic Details Submission
- Document Upload Facility
- Branch Preference Selection
- Secure Payment Integration (PayU)
- Automatic Reference Number Generation
- PDF Application Generation
- Email Confirmation Notifications

### Admin Features
- Secure Admin Login
- View and Manage Applications
- JEE Admission Management
- NRI Admission Management
- OCI Admission Management
- Overall Admission Reports
- Application Search and Filtering
